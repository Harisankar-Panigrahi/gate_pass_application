# Security Policy

## Portfolio Case-Study Security Posture

This repository is maintained strictly as an architectural case study and portfolio demonstration.

### Production Environment Protection
- **No Production Secrets:** This repository intentionally does not contain production source code, environment variables, credentials, private API keys, database connection strings, SSL certificates, signing keystores, or active access tokens.
- **Sanitized Information:** All architectural examples, diagrams, and documentation have been sanitized to remove internal hostnames, IP addresses, database schemas, and private infrastructure details.

### Reporting Vulnerabilities or Security Concerns
If you believe you have identified a security concern or architectural inquiry:
- **DO NOT** open a public GitHub Issue, Pull Request, or Discussion.
- Please report all security-related inquiries privately and directly to the repository owner:
  - **Email:** `p.harisankar03@gmail.com`
  - **LinkedIn:** [Harisankar Panigrahi](https://www.linkedin.com/in/harisankar-panigrahi/)

Please provide a clear description of the inquiry and allow adequate time for a response before disclosing any details.
